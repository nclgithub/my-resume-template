This project was created as part of my journey to learn Next.js and develop dynamic web applications. The inspiration came from websites that allow users to quickly apply resume templates. However, I noticed that many of these platforms have a limitation in customizing sections of resume.

To address this, I developed this project to provide a similar functionality but with enhanced customizability, allowing users to freely edit each section of their resume. Users can input their details, choose a template, and download their resume as a PDF with ease.

Note: Currently, the project supports only one resume template as it is still under development. More templates and customization options will be added in future updates.
